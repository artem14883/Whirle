# Адмін-панель Суші Шінобі

Сайт використовує **Decap CMS** (попередня назва — Netlify CMS) для редагування
контенту. Це не WordPress і не вимагає бази даних — усі правки одразу
зберігаються у GitHub як коміти.

## Що можна редагувати через адмін

- **Налаштування кафе:** телефон, адреса, графік, Instagram, рейтинг
- **Сет тижня:** назва, опис, ціна (стара/нова), вага, фото, дата закінчення акції
- **Hero-блок:** заголовок, опис, статистика над згином

Меню (понад 100 страв) поки лишається в коді — додати його як редаговану
колекцію можна за окрему ітерацію (потрібен переклад HTML у JSON + рендер
через JS).

## Як зайти в адмін — два способи

### Спосіб 1. Локально на ПК (для самого власника)

1. Встановити Node.js (один раз) з https://nodejs.org/
2. У PowerShell у папці проєкту запустити сервер:
   ```
   npx decap-server
   ```
3. У сусідньому терміналі підняти сайт:
   ```
   npx serve -l 3000 .
   ```
4. Відкрити **http://localhost:3000/admin/**
5. Редагувати поля → «Зберегти» → коміт автоматично йде у GitHub
   (потрібно, щоб локальний `git` був налаштований на цей репо)

Плюс цього способу: нічого додаткового платити чи деплоїти не треба.
Мінус: працює тільки з ПК, де налаштовано Node і git.

### Спосіб 2. Через Netlify Identity (з будь-якого пристрою, безкоштовно)

Netlify — це безкоштовний хостинг, який можна під'єднати поверх того ж самого
GitHub-репо. Сайт продовжує жити на GitHub Pages, а Netlify дає лише
аутентифікацію для адмін-панелі.

Кроки:

1. Зайти на **https://app.netlify.com/** → Sign up з GitHub-акаунтом
2. **Add new site → Import an existing project** → вибрати `artem14883/Whirle`
3. Build settings: лишити порожні, Publish directory: `.`, натиснути **Deploy site**
4. Після деплою: **Site settings → Identity → Enable Identity**
5. У розділі Identity → **Registration preferences** → обрати **Invite only**
   (щоб ніхто чужий не зареєструвався)
6. У тому ж розділі → **Services → Git Gateway → Enable Git Gateway**
7. У розділі Identity → **Invite users** → вписати email власника кафе
8. Власник отримає лист → клікає → встановлює пароль
9. Відкриває `https://<згенерована-назва>.netlify.app/admin/` → вводить логін → редагує

Зміни одразу комітяться у GitHub `main` → через ~1 хвилину сайт оновлюється
і на Netlify, і на GitHub Pages.

## Якщо щось зламалось

- Натиснули «Зберегти» але змін не видно → перевірити вкладку Actions у GitHub:
  https://github.com/artem14883/Whirle/actions
- Картинка завантажилась але не показується → файл має лежати в `img/dishes/`,
  адреса має починатися з `/img/dishes/`
- Адмін не пускає → перевірити, чи Identity і Git Gateway увімкнено
  на Netlify, чи власник прийняв запрошення з email
